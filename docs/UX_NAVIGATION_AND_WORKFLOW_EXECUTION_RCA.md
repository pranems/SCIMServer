## Self-improvement dispositions

- **Test/gate:** applied. Search schemas that are both URL parsers and typed router validators must test both representations.
- **Design/architecture:** accepted. Reusing the existing shared boolean parser removes divergence without adding an abstraction.
- **Review disposition:** applied. Every blocking or behaviorally meaningful finding was closed in-place. Initial Forward state remains conservatively disabled when a document starts with opaque native forward entries because browsers expose no safe forward-availability API; guessing from history length would create a false-positive navigation control.
- **JWT disposition:** accepted. The browser checks decodable JWT shape plus non-empty `sub` only to avoid an impossible shared-secret call. It does not claim validity. Signature, issuer, audience, expiry, and authorization remain server-owned; duplicating trust policy in the client would be security theater.
